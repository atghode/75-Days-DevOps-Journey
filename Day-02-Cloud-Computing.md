
# Day 2 – Cloud Computing Fundamentals

## 1. What is Cloud Computing?

Cloud computing means using computing resources such as servers, storage, databases, networking, and software over the internet instead of maintaining physical infrastructure.

## 2. Traditional IT vs Cloud Computing

- Traditional IT: We purchase and maintain physical servers.
- Cloud: We use resources on demand and pay according to usage.

## 3. Cloud Service Models

- **IaaS:** Infrastructure as a Service – Virtual machines, storage, and networking.
- **PaaS:** Platform as a Service – Managed application development platforms.
- **SaaS:** Software as a Service – Ready-to-use applications such as Gmail.

## 4. Cloud Deployment Models

- Public Cloud
- Private Cloud
- Hybrid Cloud

## 5. Major Cloud Providers

| AWS | Microsoft Azure | Google Cloud |
|---|---|---|
| EC2 | Azure Virtual Machines | Compute Engine |
| S3 | Blob Storage | Cloud Storage |
| VPC | VNet | VPC |
| RDS | Azure SQL | Cloud SQL |
| EKS | AKS | GKE |

## 6. AWS Global Infrastructure

- Region: A geographical area where AWS has infrastructure.
- Availability Zone: An isolated location within an AWS Region.

Examples:
- Mumbai: ap-south-1
- Singapore: ap-southeast-1
- North Virginia: us-east-1

## 7. AWS Shared Responsibility Model

- AWS is responsible for security OF the cloud.
- Customers are responsible for security IN the cloud.

## 8. E-commerce Architecture Example

For an e-commerce application:

- Amazon EC2: Hosts the application.
- Amazon S3: Stores product images.
- Amazon RDS: Stores customer and order data.
- Elastic Load Balancer: Distributes incoming traffic.
- Amazon CloudWatch: Monitors application and infrastructure.
